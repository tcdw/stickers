## 贴纸导出规范 / Sticker Specs

单位均为逻辑像素（px）。源文件建议保留 2 倍图以备后期调整。

- 源文件尺寸: 1024 x 1024
- 导出尺寸: 512 x 512

### Metrics

**白边 (Stroke)** 的尺寸是 10px，使用颜色 `#FFFFFF`。

以下是贴图参考尺寸：

| 内边距             | 元素最长边尺寸（不含白边） |
| ------------------ | -------------------------- |
| 44px（标准内边距） | 916px                      |
| 32px（紧凑内边距） | 940px                      |
| 24px（极限内边距） | 956px                      |

### Notes

- 所有内边距数值均包含白边。若不做白边，请额外增加 10px 留白。
- 避免关键元素（如眼睛、文字）贴近裁切边缘。
- 导出格式为 PNG 32-bit。
