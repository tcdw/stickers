## 贴纸导出规范 / Sticker Specs

单位均为基于 1024x1024 画布的逻辑像素（px）。

- 默认导出尺寸: 1024 x 1024
- 平台适配尺寸（如 Telegram）: 缩放至 512 x 512

### Metrics

**白边 (Stroke)** 的尺寸是 10px，使用颜色 `#FFFFFF`。

以下是基于 1024x1024 画布的贴图参考尺寸：

| 内边距（包含白边） | 元素最长边尺寸（不含白边） |
| ------------------ | -------------------------- |
| 44px（标准内边距） | 916px                      |
| 32px（紧凑内边距） | 940px                      |
| 24px（极限内边距） | 956px                      |

### Notes

- 所有内边距数值均**包含**白边空间。若不绘制白边，请依然保留 10px 的安全区留白。
- 避免关键元素（如眼睛、文字）贴近裁切边缘，以免在不同平台展示时被遮挡。
- 导出格式统一为 PNG 32-bit（带透明通道）。
